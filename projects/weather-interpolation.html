Project 05 · Numerical analysis · 2025

Weather Interpolation

Reconstructing smooth curves from sparse measurements — interpolation methods compared on NOAA weather data, with cubic splines at the core.

Source code

Overview

Real measurements are sparse: a station reports at fixed times, a survey samples a handful of points. This project fills the gaps. I implemented and compared linear, polynomial and cubic-spline interpolation on NOAA weather data and looked at trend, seasonal and residual components with time-series decomposition, Fourier analysis and autocorrelation.

Cubic splines win for smooth physical signals: the curve passes through every sample, and its slope and curvature stay continuous, so there are no kinks and none of the wild swings a single high-degree polynomial produces.

What the code computes

How it works

  1. SamplesStart from the measured points — here five elevation samples between 0 and 20 km.
  2. FitFit a natural cubic spline: a cubic between each pair of points, joined so slope and curvature are continuous, with zero curvature at both ends.
  3. EvaluateRead the curve anywhere between the samples — the script reports the value at 7.5 km.
  4. PlotDraw the curve on a 250-point grid together with the original samples.
