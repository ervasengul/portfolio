Projects I'm proud of

Six projects across healthcare AI, cloud infrastructure, computer vision, numerical analysis, and embedded systems — each one built to fix a pain point everyone else had accepted as normal.

01 · Graduation project

Intelligent Cluster Optimizer

A Go-based Kubernetes resource optimizer that right-sizes CPU and memory requests to cut cloud waste without risking workload stability. A statistical engine analyzes historical usage from Prometheus, and a four-layer safety framework validates every change before it lands — designed after studying where VPA, KEDA, Goldilocks, Polaris, and Karpenter fall short.

  • Go
  • Kubernetes API
  • Custom Operators
  • Prometheus
  • Docker
  • Statistical Analysis

02 · Healthcare AI

AI Pre-Evaluation for Medical Tourism

An AI pipeline that turns messy, multilingual clinical documents into clean, structured data. I fine-tuned MedGemma-4B with QLoRA to extract clinical information into structured JSON, paired NLLB-200 for translation, and assembled the results into a chronological clinical timeline that gives clinicians an ordered view of a patient's history before treatment planning.

  • Python
  • MedGemma-4B
  • QLoRA
  • NLLB-200
  • LLM Fine-Tuning
  • NLP

03 · Healthcare AI

AI Billing Anomaly Detection

A hybrid system that flags billing anomalies and SUT rule violations in healthcare transactions. A machine-learning model learns normal billing patterns while a deterministic rule engine encodes regulatory billing rules — catching both statistical outliers and explicit policy breaches, and cutting manual review effort.

  • Python
  • Machine Learning
  • Rule Engine
  • Anomaly Detection
  • Healthcare Data
Built during my internship at Medipol · private codebase

04 · TEKNOFEST 2025

Real-Time Emotion Recognition

A TEKNOFEST 2025 project that detects and classifies seven facial expressions in real time from a live webcam feed. Built on a CNN trained on facial-expression datasets, with an OpenCV pipeline for face tracking in multi-person scenes — delivered as an interactive, timed game with scoring and leaderboards that ran smoothly on standard hardware at the festival stand.

  • Python
  • TensorFlow
  • Keras
  • OpenCV
  • CNN
  • Computer Vision

05 · Numerical analysis

Weather Forecast Interpolation

Reconstructing and forecasting weather trends from NOAA meteorological data. I implemented and compared interpolation methods — linear, polynomial, and cubic splines — alongside time-series decomposition with Fourier analysis and autocorrelation to separate trend, seasonal, and residual components.

  • Python
  • NumPy
  • pandas
  • SciPy
  • Cubic Splines
  • Fourier Analysis

06 · Embedded systems

Car Battery Voltage Monitor

An embedded system on a PIC16F877A that monitors car battery voltage in real time and shows readings plus a health status (GOOD / OK / LOW / CRITICAL) on an LCD. I designed a voltage-divider circuit to safely scale the 8–15 V battery range to the ADC's 0–5 V input, and wrote the firmware in embedded C.

  • PIC16F877A
  • Embedded C
  • MPLAB X
  • ADC
  • LCD Interfacing
  • Circuit Design
