Cloud infrastructure Go · Kubernetes · 2026

Intelligent Cluster Optimizer

My graduation project, now a published arXiv paper. A Go operator reads container usage history from Prometheus, forecasts demand with Holt-Winters and right-sizes Kubernetes resource requests — every change passes four safety gates before it is applied. It cut cost by 20–40% on GKE in evaluation, backed by 1,118 automated tests.

Part. 02 — Yedik: The App · 2026 · founder & sole developer

Where your friends ate, and how much they liked it.

A social restaurant-rating app for Istanbul. No algorithm, no ads, no sponsored spots: your feed is only the people you follow.

Rate a place out of ten with a note and a photo. Keep two lists — visited, sorted by rating, and want-to-go. Add new spots from a map that already knows 225,000+ Istanbul venues. Share a rating as a story card, follow friends, get notified when they post.

I built every layer myself: the Go API (chi, pgx, sqlc, goose migrations, JWT auth), the React Native / Expo app, the PostgreSQL schema, the Docker Compose deployment on a Hetzner server behind Caddy and Cloudflare, and the CI/CD pipeline that vets, tests and builds everything on each push.

  • Go 1.25
  • chi · pgx · sqlc
  • PostgreSQL 17
  • React Native 0.86
  • Expo Router
  • TypeScript
